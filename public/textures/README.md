## Recommended Noise Texture

For the best paper effect, replace `noise.svg` with a proper WebP noise texture:
- Size: 420x420px (or similar square dimensions)
- Format: WebP for optimal compression
- File size: 6-12KB
- Should be tileable (seamless when repeated)
- Fine grain texture suitable for paper simulation

You can generate such textures using tools like:
- Photoshop/GIMP noise filters
- Online noise generators
- AI texture generators
